Έρχεται μία στιγμή στο Γυμνάσιο, συνήθως στην πρώτη τάξη του, που πρέπει να αρχίσουμε να αναπτύσσουμε τους αριθμούς σε γινόμενα πρώτων - «πρέπει» γιατί είναι μέρος της ύλης, αλλά και γιατί οι πρώτοι αριθμοί είναι ενδιαφέροντες και για άλλους πολλούς λόγους. Επομένως, κάπου εκεί, ή ίσως λίγο πιο πριν, χρειάζεται να φρεσκάρουμε λίγο τα βασικά κριτήρια διαιρετότητας που ξέρουμε από το δημοτικό και, αν χρειαστεί, γιατί όχι να δούμε και κάποια ακόμα;

Το 2, το 5, το 10...
--------------------

... και τ'άλλα παιδιά, θα μπορούσαμε να συνεχίσουμε - αλλά δε θα το κάνουμε. Ωστόσο, ας ξεκινήσουμε με τα πλέον εύκολα κριτήρια διαιρετότητας, για να ζεσταθούμε λίγο. Λοιπόν, για να δούμε αν ένας αριθμός διαιρείται με το 10, αρκεί να δούμε αν τελειώνει σε 0. Αυτό, τελεία και παύλα. Αυτό, μάλιστα, είναι γενικότερο σε κάθε σύστημα αρίθμησης με βάση έναν αριθμό :math:`b=2,3,...`: Ένας αριθμός που σε αυτό το σύστημα αρίθμησης τελειώνει σε 0 διαιρείται με το :math:`b`. Αυτό είναι λογικό αν το σκεφτείτε, αφού, για παράδειγμα, στο δεκαδικό σύστημα που έχουμε συνηθίσει, κάθε αριθμός οργανώνεται σε μονάδες, δεκάδες, εκατοντάδες, κ.λπ. Αν, λοιπόν, αποτελείται από 0 μονάδες, είναι προφανές ότι είναι σίγουρα πολλαπλάσιο του 10 (αφού δεν «περισσεύουν» μονάδες).
