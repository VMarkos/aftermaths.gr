	Ο πίνακας *Ο κατά φαντασίαν ασθενής* του `Honoré Daumier  <https://en.wikipedia.org/wiki/Honor%C3%A9_Daumier>`__. 


Σε συνέχεια των `λυμένων παραδειγμάτων στις συναρτήσεις  <docs/Διδακτικό-Υλικό/Γ-ΓΕΛ/Μαθηματικά/Σημειώσεις/λυμένα-παραδείγματα-έγχρωμα.rst>`__, ακολουθούν κάποια λυμένα παραδείγματα στα όρια. Τα παραδείγματα αυτά καλύπτουν τις βασικές περιπτώσεις απροσδιοριστιών που είναι διαχειρίσιμες χωρίς τη χρήση των κανόνων de lʹ Hôspital - αυτά τα όρια θα εξεταστούν και θα παρουσιαστούν στο τέλος της ενότητας των παραγώγων, άλλωστε.

Τα λυμένα παραδείγματα βρίσκονται `εδώ  <https://drive.google.com/file/d/17pQbGN_ewdQUBnRiU_T189cKTNpKpYcB/view?usp=sharing>`__ και στη σελίδα του `διδακτικού υλικού  <https://aftermathsgr.wordpress.com/%ce%b4%ce%b9%ce%b4%ce%b1%ce%ba%cf%84%ce%b9%ce%ba%cf%8c-%cf%85%ce%bb%ce%b9%ce%ba%cf%8c/>`__.
